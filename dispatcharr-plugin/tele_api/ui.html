TMDB

No key
Finds the missing TMDB ids, the votes and popularity of the titles, and the titles that may also please, once for every TV. Free key: themoviedb.org → Settings → API.

OpenSubtitles

No key
With a key here, every Télé TV searches and downloads subtitles through this server: nothing to set on the TVs (a key set on a TV is used first). Free key: opensubtitles.com → API consumers.

TheIntroDB

No key (optional)
Intros and end credits of the movies and episodes, from a public community base: asked by this server for the TVs and kept two weeks (two days when unknown). Without a key: 5,000 requests a day; with one: 100,000, and your own submissions count. Key: theintrodb.org → account.
